## 📊 ROI CALCULATION FORMULA

### **Basic ROI Formula**

```
ROI (%) = [(Total Revenue - Total Investment) / Total Investment] × 100

Example:
Revenue:     $66,500
Investment:  $3,600
ROI:         [($66,500 - $3,600) / $3,600] × 100 = 1,747%
```

## 💸 WHAT TO TRACK (INVESTMENT SIDE)

### **1. Time Investment**

```
YOUR TIME
• Hours spent writing: ___ hours × $[your hourly rate]
• Hours spent promoting: ___ hours × $[your hourly rate]
• Hours spent responding: ___ hours × $[your hourly rate]
• Hours spent on calls: ___ hours × $[your hourly rate]

Total Time Cost: $_____

How to calculate hourly rate:
If salaried: (Annual Salary / 2,080 hours)
If consulting: Your typical hourly rate
If entrepreneur: Opportunity cost (what else could you do?)

Example:
$150K salary / 2,080 hours = $72/hour
24 hours of work = $1,728 time cost
```

### **3. Total Investment Calculation**

```
Total Investment = Time Cost + Direct Costs

Example (from strategy):
Time Cost:       24 hours × $150/hr = $3,600
Direct Costs:    $0 (all organic)
─────────────────────────────────────────────
Total Investment:                    $3,600
```

## 🚨 WARNING SIGNS & PIVOTS

### **When to Adjust Strategy**

```
🔴 RED FLAGS (Immediate Action Required):
┌────────────────────────────────────────────────────────┐
│ • Month 1: Zero business inquiries                     │
│ • Month 2: <50 email signups                           │
│ • Month 3: Zero revenue                                │
│ • Month 6: ROI <200%                                   │
│ • Any month: Negative ROI                              │
└────────────────────────────────────────────────────────┘

Actions:
1. Review content quality (is it generic?)
```

## 📊 QUICK REFERENCE: 3 KEY FORMULAS

```
1. BASIC ROI
   ROI (%) = [(Revenue - Investment) / Investment] × 100

2. INCREMENTAL ROI (for each additional post)
   ROI (%) = [(New Revenue - New Investment) / New Investment] × 100

3. LIFETIME VALUE ROI (including all future value)
   LTV ROI (%) = [(Total Value Created - Investment) / Investment] × 100
   
   Where Total Value Created =
   Direct Revenue +
   Weighted Pipeline +
   Career Value Increase +
   Company Value Increase
```
