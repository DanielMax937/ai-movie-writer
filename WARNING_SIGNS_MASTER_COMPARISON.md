## 🎯 GENERAL PRIORITY RULES

```
RULE 1: Red Before Yellow Before Green
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Always fix critical issues (red) before optimizing (yellow).
Only focus on scaling (green) when foundation is solid.

Exception: If green signal shows demand you can't handle,
           address capacity constraint immediately.

RULE 2: Revenue Red Flags First
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Within red flags, prioritize revenue-related issues:
1. Red #3 (zero revenue) - most critical
2. Red #1 (zero inquiries) - pipeline is empty
3. Red #2 (<50 signups) - future pipeline
4. Red #4 (ROI <200%) - underperforming
5. Red #5 (negative ROI) - stop the bleeding

RULE 3: Quick Wins First Within Same Severity
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
If multiple yellow flags, prioritize by:
1. Time to fix (faster wins first)
2. Revenue impact (higher impact first)
3. Ease of implementation (easier first)

Example: Yellow #3 (email subject lines) is faster than
         Yellow #1 (list growth strategy) → fix #3 first

RULE 4: Don't Ignore Green While Fixing Red/Yellow
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
If you have green signals, maintain them while fixing issues.

Example: List growing >30% (green) + close rate <20% (yellow)
         → Keep posting to maintain list growth
         → But focus optimization effort on close rate

RULE 5: One Focus at a Time (Unless Easy Parallel)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Don't try to fix everything simultaneously.

Pick 1-2 issues max and focus until resolved.

Exception: If issues have completely independent action plans
           (e.g., posting schedule + sales script practice)
```
